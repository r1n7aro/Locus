# Changelog

## 0.1.0

- Migrated the default Unity plugin install location to `Packages/com.farlocus.locus`.
- Added `LocusEditorWindow.SendToLocus(SendToLocusMode)` for sending the current selection to the focused session or a new session draft.
- Added the `LocusFileAttachment` overload for sending explicit local files or folders with either session mode.
