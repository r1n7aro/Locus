## Changes

### v0.9.3 (Added)

- Blender integration. Detect or add Blender installations in Settings > Integrations > Blender and install or update the add-on in one click. The Agent runs bpy code on the main thread of a running Blender through `blender_execute` and gets back printed output, the return value, and viewport images; the Python SDK adds `locus.blender`. The chat status bar shows the Blender connection, and background instances have a limit on how many run at once and an idle shutdown time.
- Remote access from a phone (experimental, off by default). Turn it on in Settings > Connections > Remote Access and pair the Android app Locus Remote by scanning a QR code. From the phone you can browse sessions and live output, send messages, stop runs, answer questions, and read project files and knowledge documents. Phones connect over the LAN, directly over Tailscale, or through a tunnel to a local address. Paired devices can only view and chat by default; approving tool calls and changing content requires `Full control`.
- New installer `Windows x64 - with Locus Remote (Android)`, which bundles the matching Locus Remote app so a phone can download it from the computer while pairing.
- Settings is reorganized into seven groups (Models, Agent, Workspace, Integrations, Interface, Connections, System) and can be searched. All settings are stored in one place, and older settings, including interface preferences, migrate automatically. Project settings are saved in the project's `Locus/config.json` and can be shared through the repository.
- The Agent can read and change Locus settings through `config_query` and `config_set`. Changing settings and changing sensitive settings are controlled separately under Tool Permissions.
- When the main model is Claude Code and Multi-Agent is on, delegation can use Claude Code's own `Agent` and `SendMessage` tools (requires Claude Code 2.1.312 or later). A one-line notice appears in the conversation when a background agent finishes, and tool confirmations from sub-agents appear in the current conversation with their source.
- With Multi-Agent on, agents get a `send_message` tool to message their parent, sub-agents, or sibling agents directly. The background tasks panel can stop all agents at once.
- Subagent models can be multi-selected. The delegating agent picks one per task; the first is the default.
- LaTeX preview. `.tex` files can be previewed next to the editor and recompile after edits only while the preview is visible; a failed build keeps the last successful result. The toolchain is detected from PATH and the default MiKTeX and TeX Live install locations; documents fall back to PDF when dvisvgm is missing or the document needs it.
- File previews show FBX and GLB models with grid, wireframe, and clay display, play animation clips, and list mesh, triangle, and bone counts and the model size.
- PDF files open in the workspace file editor, including PDFs inside Unity project folders, instead of the asset inspector.
- Images in chat and Markdown open in a lightbox where you can zoom, fit to the window, or view the original size.
- The message context menu adds `Copy as image`, which copies the message as rendered to the clipboard as a PNG.
- The folder for pasted images can be set in the project settings or chosen per document in the editor; documents reference the images by relative path.
- When adding a workspace, choose Auto, Lazy, or Off for Unity and for Blender. A new global `Enable Unity` switch stops connecting to the Unity Editor, scanning assets, and offering Unity tools when turned off.
- Files and folders can be dragged from the system file manager into the workspace explorer to import them; Locus asks before overwriting a file with the same name.
- After selecting text in a document, `Quote in new conversation` opens a new session that quotes it. The editor tab context menu adds `Reveal in Workspace` and `Open in File Browser`.
- `unity_execute` adds a `timeout` parameter (10 minutes by default, up to 1 hour). Runtime exceptions in snippets show line numbers within the snippet, and a snippet that is a single expression returns its value.
- `unity_code_usages` finds `[SerializeReference]` instances (including overrides on prefab instances, variants, and nested prefabs) and serialized values of plain `[Serializable]` types. `code_diagnostics` checks that the types recorded by `[SerializeReference]` still exist.
- Merging several selected commits applies them in order, like a series of cherry-picks, and a whole branch can be merged as one squash. `change_summary()` summarizes changes per file, deleting an object is a single decision, and merged scenes are written in Unity's own fileID order.

### v0.9.3 (Fixed)

- With many session tabs open, each editor group keeps only the 6 most recent sessions loaded by default (adjustable in Settings), and hidden sessions and previews stop rendering updates. Long sessions load the latest 120 messages first and earlier messages on demand.
- The thinking indicator, running session titles, and tab animations run on the compositor only and no longer repaint the whole window.
- Unity connection, code analysis, knowledge indexing, asset scanning, background tasks, and Claude connection status are pushed by the backend instead of polled on a timer.
- Any window can act as the primary window. Locus exits or minimizes to the tray only when the last window closes, and pop-out windows close with the window that opened them.
- The workspace layout tree and file order are stored in the Locus data directory instead of the project's `Locus/workspace-trees` and `Locus/workspace-file-order.json`. Existing data is imported automatically.
- Moving a PDF tab after its preview data expired reads the PDF again instead of failing to load it.
- Workspaces outside a Git repository no longer show the worktree picker.
- Long commands (over about 8 KB) run through sh on Windows are no longer cut off.
- After Claude Code compacts the context natively, Locus appends the user's own messages, the task list, and excerpts of files read through Locus tools to the summary.
- File paths in streaming replies become clickable references while the reply is still streaming. Selections inside Markdown table cells display correctly.
- Tracebacks from the `python` tool show line numbers that match the submitted code.
- Unity YAML with empty-string keys (such as plugin `.meta` files) can be parsed, edited, and merged. Large scenes are handed to the Editor through staged files in the project's `Library`, so they are no longer limited by the connection's request size.
- The Unity native plugin is renamed to `locus_unity_native.dll` and shares a new native communication layer with Blender; the old `locus_native.dll` is removed automatically on update.
- Find-in-document highlights are easier to see, and the current match uses a darker color.

### v0.9.3 (Removed)

- The Settings > Experimental page is removed and its options moved to the relevant pages. Async tasks no longer need a switch: `bash`, `unity_test_run`, and `task` can always run in the background.

### v0.9.2 (Added)

- Markdown documents support comments. Select text and add a comment from the context menu or with Ctrl+Alt+M. Comments can be replied to, edited, resolved, and reopened, and appear in the right margin of knowledge documents and file previews. They are stored in a hidden block at the end of the Markdown file, so other Markdown renderers do not show them. Set the name shown on your comments in Settings > General.
- Markdown documents support footnotes (`[^label]`). Insert one from the context menu or with Ctrl+Alt+F. References show as numbered superscripts; click one to view and edit the note.
- Markdown documents reopen where you stopped reading. Knowledge documents keep their position after renames and moves, and worktrees of the same project share it.
- Workspace folders can be renamed in the file explorer. Unity `.meta` files, knowledge entries, layout references, and file order move with the folder.
- Stopping a `unity_execute` run also stops loops that hold the Unity main thread: loops in the snippet exit at their next iteration, so an endless loop no longer requires restarting the Editor. An Editor that was open during the update needs one restart to load the new native plugin.
- Python SDK: new `cancel_unity_execution(...)` stops a detached Unity execution, even while it holds the main thread.
- While Unity's main thread stays unresponsive, the hang diagnosis keeps sampling. The status panel and Agent reports show how long it has lasted, whether Unity, project code, or Agent code is running, whether it looks like a deadlock or an endless loop, and the call that has not returned.

### v0.9.2 (Fixed)

- Unity recompiles keep waiting while Unity is compiling, importing, or running initializers, for up to 3 minutes without response, and recompile results can be read while the main thread is busy. If the hang diagnosis shows the Editor will not recover, the recompile reports where it is stuck.
- If another recompile is already running, Locus waits for it and then compiles again so the current sources are loaded. After a "no recompile needed" result, it waits for any compile or import Unity starts right after.
- A long `unity_execute` run is no longer cancelled as a lost client when Unity's busy main thread delayed the client's progress checks. When a detached run stalls, the message explains how to cancel it or read its result later.
- Switching to a session that is still replying no longer loses or repeats text streamed while the session loads.
- With several windows open, streamed replies and file changes are sent only to windows that show that session or workspace.
- Bursts of file changes are batched. After a folder is rescanned, deleted, or renamed, the explorer, diff previews, file times, and Markdown images refresh everything below it.
- Rendered Markdown in chat and previews refreshes only when a file it references changes, and resolves paths against its own workspace.
- Window state is saved as small incremental changes. Unsaved edits to large files save only the changed part, and files without unsaved changes are no longer copied into the saved state; they reload from disk.
- Restoring a maximized window no longer shows it at its normal size first. Windows opened in the background no longer take focus, and pop-up windows accept dragged files.
- Opening several windows at once no longer creates an extra pop-up window that never becomes available.
- Document draft recovery is stored in the Locus data directory as incremental changes, and opening an unchanged document writes nothing. Existing drafts are migrated automatically.
- Sessions in a workspace whose current branch was picked in the worktree picker no longer appear moved to another checkout. Affected sessions are reattached at startup, and session tabs follow their session's workspace.
- Fixed several issues in the Claude Code CLI path.
- Codex models that return `tool_search` as a namespaced call (Responses Lite) can load deferred tools.
- The asset text viewer shows whole source files (up to 20,000 lines or 2 MB). For larger files, the truncation notice appears at the end of the code.
- Tool calls merged into a reply from earlier tool-only rows appear before its thinking and text; knowledge proposals stay at the end.
- Saving long streamed replies no longer slows down as the reply grows.
- In the Markdown editor, shrinking a full-line selection to part of a line no longer paints the selected text twice.

### v0.9.1 (Added)

- You can choose where new worktrees are stored in Settings; by default they go next to the repository. The `--locus-worktree-root` launch option or the `LOCUS_WORKTREE_ROOT` environment variable overrides it for one run.
- Worktrees can now be created for repositories with submodules and for projects that use local packages inside the repository (`file:` dependencies).
- Worktree creation shows how many files have been checked out. Closing the picker no longer stops it: creation continues in the background and appears in the background task list of every window.
- A session that runs in a worktree stays in its workspace's layout, and its tab shows the worktree. New sessions start in the worktree you last chose for the project, and the chat input shows the current branch.
- Worktrees created by Locus are no longer listed as separate recent workspaces; you open them from their source workspace.
- The file explorer can create and delete folders. Select several items with Ctrl/Shift to copy their paths, delete, hide, or drag them together.
- Editor tabs can open local files outside the workspace, for example from file references in chat. These tabs are marked "Outside workspace".
- In a new session that has not started yet, the chat input attaches the text selected in the current document (path, line numbers, and content). You can remove the attachment.
- You can `@` mention local and remote Git branches in the chat input.
- The Collaboration and Agent pages now open on top of the list and editor tabs, and closing them restores the previous layout. On narrow widths the Collaboration page shows only the commit history.
- Asset search finds glTF models, Shader Graph files, and common text, UI Toolkit, and assembly definition files. The asset index is rebuilt once when a project is first opened.
- When merging branches, code and plain-text files merge line by line with a three-way merge. Conflicts are shown with diff3 markers, and the Agent can write the merged result directly.
- Prefab overrides, objects added to or removed from prefab instances, managed references, and similar lists merge element by element.
- After a merge is applied, Unity reimports the written assets and reloads open scenes and prefabs from disk. Assets with unsaved changes are reported and never overwritten.
- OpenRouter endpoints can turn on server-side web search and choose the search engine (Auto, native, Exa, Parallel, Firecrawl, Perplexity). Search sources appear as citations, and later turns can use them without searching again.
- When signed in with a Codex subscription, Codex models can use Codex's built-in web tool to search, open pages, and find text on a page.
- The Agent can ask several questions at once. You can pick multiple options, write your own answer, move between questions, and submit all answers together. The Python SDK's `run.answer` accepts questionnaire answers.
- Claude Code sessions show the current stage in the conversation, such as preparing, thinking, calling tools, or writing a reply.
- When Claude Code fails to start in the background, the reason is shown in the status bar. After a lost connection, it reconnects and restores the conversation automatically.
- You can set Claude Code's auto-compact threshold. Results of Claude's native task tools are shown as to-do lists.
- Context statistics check prompt cache reuse for each request and show how many requests could be checked.
- Cost shows only what the provider reports; when the provider reports none, it shows "Not reported".
- The session database is cleaned up in the background: old request captures are removed and the file is compacted, with progress shown. Locus tells you when there is not enough disk space.
- The Claude subscription model list now has Opus 5.5 (default), Fable 5.1, Sonnet 5.5, and Haiku 5.5.
- Python SDK: new `worktrees.defaults()`, and the directory can be omitted when creating a worktree; merge jobs have new `all_changes()` and `set_text()`.

### v0.9.1 (Fixed)

- Workspace and Workbench windows opened while Locus is running now accept files dragged in from your computer.
- Knowledge documents save in the background without locking the title or property buttons, and the page no longer shifts while saving.
- Only CSV knowledge documents show the unsaved marker, and the file editor no longer flashes the disk conflict bar during autosave.
- Renaming a Markdown document's title keeps focus in the input.
- Long cells in Markdown tables wrap within the available width. When a table scrolls sideways, its first column stays in place and edge shadows appear.
- In `@` mentions and global search, file-name matches come before path matches, and scattered matches across long paths no longer appear.
- Queued messages and messages inserted mid-run are no longer lost or sent twice before delivery is confirmed. Undelivered messages are kept and marked "Not delivered" so you can edit or resend them.
- When the Codex service refuses an inserted message, the session stops inserting messages and retries the request.
- With web search on Anthropic-format endpoints, earlier search results are sent back to the model in their original format, so the model no longer treats them as its own text and makes up results.
- `web_fetch` recognizes pages that do not declare their encoding, checks the destination of every redirect, and converts large HTML pages more reliably.
- Grep and Claude Code's Grep now use the same search engine and are faster in large workspaces.
- The Locus Unity plugin compiles on older Unity versions. Unsupported features (frame timing stats, spatial capture) state which Unity version they need.
- When a Unity test run starts, it reports the number of tests that actually run after filtering.
- Lists in Unity assets keep their original layout; only changed elements are written.
- Exporting and forking sessions no longer copies the whole database, so they finish on large databases.
- Full model request captures are recorded only in debug mode, which keeps the session database from growing quickly.
- If the data directory is in use by another Locus process, startup shows a dialog explaining why instead of crashing.
- The Git branch list correctly handles branches checked out in other worktrees and a detached HEAD.
- "Delete workspace" in the workspace tree is now "Remove workspace"; it only removes the workspace from the tree and does not delete any files.

### v0.8.0 (Added)

- **Concurrent multi-workspace operation.** Multiple projects and Git worktrees can run in one Locus instance, with parallel sessions, Unity connections, Knowledge indexes, asset databases, and workspace services. Each workspace keeps an independent execution context, runtime state, and resource cache.
- **VS Code-style split workbench.** Sessions, files, Knowledge documents, Unity assets, and Views open as editor tabs. Tabs can be reordered, split in four directions, moved between panes, or detached into native windows. Window layouts, tabs, drafts, scroll positions, and unsaved content can be restored.
- **Development workspace tree.** Sessions, Knowledge, collaboration, and files now share one workspace tree, with single- and multi-workspace layouts, saved presets, virtual folders, mounted directories, and per-node visibility controls.
- **Persistent Markdown editing.** Knowledge documents now use CodeMirror 6 for Live Preview and source editing, preserving selections, undo history, scroll position, drafts, and unsaved changes across document switches and split panes.
- **Expanded Knowledge workflows.** Added `Plan` as a fifth knowledge type, writable project Skill packages under `Locus/skills`, automatic Skill refresh, document outline navigation, cached loading, and conflict-aware collaborative editing.
- **Workspace and Unity mentions.** Chat `@` search now covers workspace files and folders as well as live Unity scene objects, with ranked results and explicit object references.
- **Richer Unity inspection.** `unity_yaml_read` can display selected hierarchy metadata, including active state, Prefab source, world transforms, RectTransform bounds, tags, layers, and components. SubScene reads can follow the authoring Scene hierarchy, and adjustable serialized fields can render as inline property controls.
