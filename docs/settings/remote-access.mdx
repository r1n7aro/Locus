---
title: 远程访问
description: 用手机上的 Locus Remote 浏览会话、文件和知识库，发送消息、回答提问
---

远程访问让配对过的手机通过 **Locus Remote** App 连接这台电脑上的 Locus：浏览各项目的会话、查看实时输出、发送消息、停止运行、回答 Agent 的提问，还可以浏览项目文件和知识文档。会话照常在电脑上运行，手机只是另一个窗口。

远程访问目前是实验性功能，默认关闭。关闭时 Locus 不监听任何端口，也没有额外的后台任务。

## 开启

打开「设置」→`工具`分组→`远程访问`，打开`开启远程访问`。开启前会弹出安全警告，说明已配对设备能在这台电脑上做什么，确认后才会开启；关闭不需要确认。然后在`网络`里选择手机从哪里连接：

- **`局域网与 Tailscale 直连`**：打开手机能访问到的网卡。Locus 在这些地址上提供 HTTPS，使用本机生成的自签证书，并只接受同一局域网（或同一 tailnet）内的设备。首次开启时 Windows 可能弹出防火墙提示，请允许 Locus 通过**专用网络**；页面上的`打开防火墙设置`可直接跳转。
- **`本机地址（供隧道转发）`**：在 `127.0.0.1` 上提供 HTTP，供在本机终止加密的工具转发，例如 `tailscale serve`、UU 远程端口映射、frp。页面会给出 `tailscale serve` 命令示例。
- **`HTTPS 主机名`**：使用 `tailscale serve` 这类提供有效证书的代理时，填写手机访问用的主机名（如 `my-pc.tailnet.ts.net`）。
- **`端口`**：所有地址共用一个端口，默认 47831。修改后需要同步更新隧道配置。

穿透服务都是可选的：同一 Wi-Fi 下只用局域网直连即可。

## 配对手机

1. 在手机上安装并打开 Locus Remote（还没有 App 时见下一节）。
2. 在电脑上点击`配对新设备`，弹出二维码，有效期 2 分钟。
3. 在手机上点`扫码配对`扫描二维码。
4. 电脑上会弹出「某设备请求配对」，确认是你自己的手机后点`允许`。

二维码里包含本机证书的指纹，手机只信任这张证书，因此即使在不受信任的网络里，连接也无法被冒充。经 `HTTPS 主机名` 连接时，也可以在 App 里选择`输入配对码`，输入弹窗中的 6 位数字。

每次配对最多允许输错 5 次，超过或超时后需要重新生成。

## 从电脑下载 App

安装包 **Windows x64 - with Locus Remote (Android)** 内置了与这台 Locus 版本一致的 Locus Remote Android 安装包，手机可以直接从电脑下载，不需要外网：

1. 在电脑上点击`配对新设备`。
2. 用手机**相机**（不是 App）扫描二维码，浏览器会打开电脑提供的下载页，点`下载 Android 版`。
3. 安装后打开 Locus Remote，点`扫码配对`再扫一次同一个二维码；二维码过期了就在电脑上重新生成。

同一个二维码对 App 来说是配对码，对相机来说是下载链接。下载只在打开配对窗口后的 10 分钟内提供，经局域网直连地址时使用普通 HTTP（只提供下载页和安装包，令牌等内容从不经过明文）。可以在`允许从本机下载 App`里关闭这项功能。

没有内置安装包或关闭了下载时，用相机扫码会打开一个说明页，提示在 Locus Remote 里扫码，并给出官方发布页的链接。二维码指向的始终是这个普通 HTTP 页面，所以浏览器不会因为本机的自签证书提示"证书不安全"。

**注意：**局域网下载无法防止同一网络中的人篡改安装包。请只在信任的网络（例如家里的 Wi-Fi）中这样安装；在公司或公共网络中，请改从官方发布页下载。通过 Tailscale 直连地址或 `HTTPS 主机名` 下载时，传输本身经过加密和认证，不受此影响。安装之后，手机只会接受同一签名的更新。

微信内置浏览器无法下载安装包，请按页面提示改用系统浏览器打开。Locus Remote 目前只有 Android 版。

## 在手机上浏览文件和知识库

项目卡片下方的`文件`和`知识库`分别打开项目目录和知识库：

- **文件**：逐级浏览目录，或在顶部搜索文件。Markdown 会渲染显示（包括文档里引用的图片），CSV 显示为表格，代码带语法高亮，图片、音视频直接显示；大文件只显示开头部分。
- **知识库**：按设计、计划、记忆、参考、技能分类浏览文件夹和文档，或在顶部搜索全部知识文档。打开的文档会先显示来源、更新时间和摘要，Markdown 与 CSV 文档都能阅读。
- **查看页**：文档里的相对链接、文件引用和知识文档引用点开后继续在手机上打开，`#标题`链接跳到对应位置；较长的 Markdown 可以用右上角的`目录`跳转。点图片进入大图，可以双指缩放、双击放大。右上角菜单可以刷新、复制路径或复制全文。
- **跟随电脑上的修改**：Agent 或你在电脑上改动了正在查看的文件、所在文件夹或知识文档，手机上的内容会自动更新，并保持当前阅读位置。
- 对话里提到的文件、文件夹和知识文档，以及工具调用上的"预览文件"按钮，在手机上都会打开同一个查看页。

## 设备与权限

`已配对设备`列出每台手机的在线状态、上次连接的时间和地址：

- **`完全控制`**：允许这台设备批准需要确认的工具调用（运行命令、修改文件等），并使用会修改内容的功能，例如编辑文件、Git 操作、修改知识文档和设置。默认关闭，此时设备只能查看和对话：浏览会话、文件和知识库，发送消息、停止运行、回答普通提问；需要确认的工具调用只能在电脑上完成。
- **`撤销`**：立即断开并让该设备失效，需要重新配对才能再连接。

设备超过`闲置失效`天数（默认 30 天）未连接，也需要重新配对。

## 安全说明

- 手机能调用哪些功能由电脑决定：未开启完全控制的设备只能查看和对话，读取文件时也只能访问已打开的项目目录；开启完全控制后可以做修改。
- 有些功能始终只能在电脑上使用：远程访问本身的管理（配对、撤销、改设置）、会返回明文密钥的配置（自定义模型服务商、MCP 服务器）、电脑上的窗口与 Unity 界面、打开资源管理器等系统操作、需要在电脑上选择文件的导入导出。
- 电脑只保存令牌的哈希；手机把令牌加密保存在系统密钥库中，并禁止随应用备份迁移。
- 浏览器无法访问远程访问服务，电脑会拒绝所有来自网页的请求。
- `重置证书`会撤销所有已配对设备，适合怀疑证书或设备泄露时使用。

## 目前的限制

- 手机上目前只能阅读文件和知识文档，还不能直接编辑；Unity 界面、视图（View）等电脑专属功能不可用。
- App 在后台时不会收到推送通知，回到前台后自动重连并刷新。
- 电脑的局域网地址变化后，如果手机连不上，请重新扫码配对。
