## 变更列表

### v0.9.3（新增）

- 新增 Blender 集成。在“设置 > 集成 > Blender”中检测或手动添加 Blender，并一键安装或更新插件。Agent 通过 `blender_execute` 在正在运行的 Blender 主线程上执行 bpy 代码，返回打印输出、返回值和视图截图；Python SDK 新增 `locus.blender`。对话状态栏显示 Blender 连接状态；后台实例可以设置同时运行的上限和空闲关闭时间。
- 新增手机远程访问（实验性，默认关闭）。在“设置 > 连接 > 远程访问”中开启后，用 Android 版 Locus Remote 扫码配对，就可以在手机上浏览会话和实时输出、发送消息、停止运行、回答提问，并阅读项目文件和知识文档。连接方式支持局域网、Tailscale 直连和本机地址隧道转发。设备默认只能查看和对话，开启“完全控制”后才能批准工具调用和修改内容。
- 新增安装包“Windows x64 - with Locus Remote (Android)”，内置与当前版本一致的 Locus Remote。手机配对时可以直接从电脑下载 App。
- 设置页重新整理为模型、Agent、工作区、集成、界面、连接、系统七个分组，可以搜索设置项。所有设置统一保存，旧版设置（包括界面偏好）会自动迁移。项目级设置保存在项目的 `Locus/config.json` 中，可以随仓库共享。
- Agent 可以通过 `config_query` 和 `config_set` 读取和修改 Locus 设置。“修改设置”和“修改敏感设置”分别在“工具权限”中控制。
- 主模型为 Claude Code 并开启 Multi-Agent 时，可以改用 Claude Code 自带的 `Agent` 和 `SendMessage` 委派（需要 Claude Code 2.1.312 或更高版本）。后台 Agent 结束时，对话中会显示一行提示；子 Agent 的工具确认显示在当前对话里，并标注来源。
- 开启 Multi-Agent 后，Agent 多了 `send_message` 工具，可以直接给父 Agent、子 Agent 或同级 Agent 发消息。后台任务面板可以一次停止全部 Agent。
- 子代理模型可以多选。委派时 Agent 按任务从中选择，第一个为默认。
- 新增 LaTeX 预览。`.tex` 文件可以在编辑器旁预览，修改后只在预览可见时重新编译；编译失败时保留上一次成功的结果。工具链从 PATH 以及 MiKTeX、TeX Live 的默认安装目录检测；缺少 dvisvgm 或文档需要时改用 PDF 显示。
- 文件预览可以查看 FBX 和 GLB 模型，支持网格、线框和白模显示，可以播放动画片段，并显示网格、三角面、骨骼数量和尺寸。
- PDF 文件在工作区文件编辑器中打开，Unity 项目文件夹里的 PDF 也一样，不再进入资产检查器。
- 聊天和 Markdown 中的图片点击后在大图中打开，可以缩放、适应窗口或查看原始大小。
- 消息右键菜单新增“复制为图片”，按界面渲染效果复制为 PNG。
- 粘贴图片的保存位置可以在项目设置中指定，也可以在编辑器中为某个文档单独选择，文档里用相对路径引用。
- 添加工作区时，可以分别为 Unity 和 Blender 选择“自动 / 按需 / 关闭”。新增全局“启用 Unity”开关，关闭后不连接 Unity Editor、不扫描资源，也不提供 Unity 工具。
- 可以把系统文件管理器里的文件和文件夹拖进工作区资源管理器导入，遇到同名文件会先询问是否覆盖。
- 在文档中选中文字后，可以“打开新会话并引用”。编辑器标签页的右键菜单新增“在工作区中定位”和“在文件浏览器中打开”。
- `unity_execute` 新增 `timeout` 参数（默认 10 分钟，最长 1 小时）。代码片段的运行时异常会显示片段内的行号；整个片段只有一个表达式时，直接返回它的值。
- `unity_code_usages` 可以查到 `[SerializeReference]` 实例（包括预制体实例、变体和嵌套预制体上的覆盖）和普通 `[Serializable]` 类型的序列化值。`code_diagnostics` 会检查 `[SerializeReference]` 记录的类型是否还存在。
- 合并时选择的多个提交按顺序应用，效果类似连续 cherry-pick；支持把整条分支合并为一次（squash）。`change_summary()` 按文件汇总变更。删除一个对象只需要做一次决定。合并后的场景按 Unity 自己的 fileID 顺序写入。

### v0.9.3（修复）

- 打开多个会话标签页时，每个编辑器组默认只保持最近 6 个会话加载（可以在设置中调整），隐藏的会话和预览不再渲染更新。很长的会话先加载最近 120 条消息，更早的消息按需加载。
- 思考提示、运行中的会话标题和标签页动画只在合成层播放，不再让整个窗口重绘。
- Unity 连接、代码分析、知识库索引、资源扫描、后台任务和 Claude 连接状态改为由后端推送，不再定时轮询。
- 任何窗口都可以作为主窗口。只有关闭最后一个窗口时才会退出或最小化到托盘；弹出窗口跟随打开它的窗口一起关闭。
- 工作区布局树和文件排序改为保存在 Locus 数据目录中，不再写入项目的 `Locus/workspace-trees` 和 `Locus/workspace-file-order.json`。已有数据会自动导入。
- 移动标签页后，预览数据已经过期的 PDF 会重新读取，不再加载失败。
- 不在 Git 仓库里的工作区不再显示 worktree 选择器。
- 在 Windows 上通过 sh 运行的长命令（超过约 8 KB）不再被截断。
- Claude Code 原生压缩上下文后，Locus 会在摘要后补上用户自己的消息、任务列表和通过 Locus 工具读过的文件摘录。
- 流式回复中的文件路径在输出过程中就能识别为可点击的引用。Markdown 表格单元格里的选区可以正常显示。
- `python` 工具报错时，回溯里的行号对应提交的代码。
- 可以解析、编辑和合并包含空字符串键的 Unity YAML（例如插件的 `.meta` 文件）。写入大场景时，内容通过项目 `Library` 中的暂存文件交给 Editor，不再受连接请求大小限制。
- Unity 原生插件改名为 `locus_unity_native.dll`，和 Blender 共用新的原生通信层；更新时会自动移除旧的 `locus_native.dll`。
- 文档内查找的匹配高亮更清晰，当前匹配使用更深的颜色。

### v0.9.3（移除）

- 移除“设置 > 实验性”页面，其中的选项移到了对应的页面。“异步任务”不再需要开关，`bash`、`unity_test_run`、`task` 始终可以在后台运行。

### v0.9.2（新增）

- Markdown 文档支持批注。选中文字后，从右键菜单或按 Ctrl+Alt+M 添加批注。批注可以回复、编辑、解决和重新打开，显示在知识文档和文件预览的右侧边栏。批注保存在 Markdown 文件末尾的隐藏块中，其他 Markdown 渲染器不会显示。可以在“设置 > 通用”中设置批注署名。
- Markdown 文档支持脚注（`[^label]`）。从右键菜单或按 Ctrl+Alt+F 插入，引用显示为带编号的上标，点击即可查看和编辑脚注内容。
- 重新打开 Markdown 文档时，会回到上次阅读的位置。知识文档重命名或移动后仍保留位置，同一项目的各个 worktree 共用阅读位置。
- 文件资源管理器可以重命名工作区文件夹。Unity `.meta` 文件、知识条目、布局引用和文件排序会随文件夹一起更新。
- 停止 `unity_execute` 时，占住 Unity 主线程的循环也会停止：代码片段中的循环会在下一次迭代时退出，死循环不再需要重启 Editor。更新时已经打开的 Editor 需要重启一次，才能加载新的原生插件。
- Python SDK 新增 `cancel_unity_execution(...)`，可以停止后台运行的 Unity 执行，即使它正占住主线程。
- Unity 主线程持续无响应时，卡死诊断会持续采样。状态面板和 Agent 报告会显示持续时长、正在运行的是 Unity 自身、项目代码还是 Agent 代码、是否像死锁或死循环，以及一直没有返回的调用。

### v0.9.2（修复）

- Unity 正在编译、导入或运行初始化代码时，重编译会继续等待，最多容忍 3 分钟无响应；主线程繁忙时也能读取重编译结果。如果卡死诊断显示 Editor 无法自行恢复，重编译会报告卡住的位置。
- 已有其他重编译在进行时，Locus 会等它完成后再编译一次，确保加载的是当前源码。得到“无需重编译”的结果后，会等待 Unity 紧接着开始的编译或导入完成。
- Unity 主线程繁忙导致客户端的进度检查延迟时，长时间运行的 `unity_execute` 不再被当作客户端断开而取消。后台运行卡住时，提示信息会说明如何取消或稍后读取结果。
- 切换到仍在回复的会话时，加载期间流式输出的文字不再丢失或重复。
- 打开多个窗口时，流式回复和文件变化只发送给显示该会话或工作区的窗口。
- 大量文件变化会合并处理。文件夹被重新扫描、删除或重命名后，资源管理器、差异预览、文件时间和 Markdown 图片会刷新其下的全部内容。
- 聊天和预览中渲染的 Markdown 只在其引用的文件变化时刷新，并按它所属的工作区解析路径。
- 窗口状态改为按增量保存。大文件的未保存修改只保存改动部分；没有未保存修改的文件不再复制到保存的状态中，恢复时从磁盘读取。
- 恢复最大化的窗口时，不再先以普通大小闪现。在后台打开的窗口不再抢占焦点，弹出窗口可以接收拖入的文件。
- 同时打开多个窗口时，不再多创建一个始终不可用的弹出窗口。
- 文档草稿恢复数据改为以增量形式保存在 Locus 数据目录中，打开未修改的文档不会写入任何内容。已有草稿会自动迁移。
- 在 worktree 选择器中选中工作区的当前分支后，该工作区的会话不再显示为已移到其他检出。受影响的会话会在启动时重新关联，会话标签页跟随会话所属的工作区。
- 修复了 Claude Code CLI 路径的一些问题。
- 以命名空间形式返回 `tool_search` 的 Codex 模型（Responses Lite）可以正常加载延迟工具。
- 资产文本查看器可以显示完整的源文件（最多 20,000 行或 2 MB）。更大文件的截断提示显示在代码末尾。
- 从之前仅含工具调用的消息合并进来的工具调用，会显示在回复的思考和正文之前；知识提议仍显示在最后。
- 保存很长的流式回复时，速度不再随回复变长而下降。
- 在 Markdown 编辑器中把整行选区缩小到行内一部分时，选中的文字不再被重复绘制。

### v0.9.2（移除）

- 本版本没有移除面向用户的工作流或兼容路径。

### v0.9.1（新增）

- 可以在设置中指定新 worktree 的存放位置，默认放在仓库旁边；也可以用启动参数 `--locus-worktree-root` 或环境变量 `LOCUS_WORKTREE_ROOT` 临时指定。
- 包含子模块的仓库，以及使用仓库内本地包（`file:` 依赖）的项目，现在可以创建 worktree。
- 创建 worktree 时显示已检出的文件数。关闭选择面板后创建会在后台继续，所有窗口的后台任务列表中都能看到。
- 在 worktree 中进行的会话保留在所属工作区的布局里，标签上会标出所在的 worktree。新会话默认使用该项目上次选择的 worktree，输入框底部会显示当前分支。
- Locus 创建的 worktree 不再作为单独的工作区出现在最近列表中，而是从源工作区进入。
- 文件管理可以新建和删除文件夹。用 Ctrl/Shift 多选后，可以批量复制路径、删除、隐藏或拖动移动。
- 编辑器标签可以打开工作区以外的本地文件（例如从聊天中的文件引用打开），标签上标注“工作区外”。
- 尚未开始的新会话中，聊天输入框会把当前文档里选中的文本作为附件带上（路径、行号和内容），可以手动移除。
- 聊天输入框可以 `@` 提及本地和远程 Git 分支。
- 协作页面和 Agent 页面改为覆盖在列表和编辑器标签上方打开，关闭后恢复原布局。协作页面较窄时只保留提交历史。
- 资产搜索可以找到 glTF 模型、Shader Graph，以及常见的文本、UI Toolkit 和程序集定义文件。首次打开项目时会重建一次资产索引。
- 合并分支时，代码和纯文本文件按行三方合并，冲突处用 diff3 标记显示，Agent 可以直接写入合并结果。
- 预制体覆盖、实例中新增或移除的对象、托管引用等列表在合并时按元素合并。
- 应用合并后，Unity 会重新导入写入的资产，并从磁盘重新加载打开的场景和预制体；有未保存修改的资产只会被报告，不会被覆盖。
- OpenRouter 端点可以开启服务端网页搜索并选择搜索引擎（自动、native、Exa、Parallel、Firecrawl、Perplexity）。搜索来源显示为引用，后续轮次无需重新搜索。
- 使用 Codex 订阅登录时，Codex 模型可以使用 Codex 自带的网页工具，包括搜索、打开网页和页内查找。
- Agent 可以一次提出多个问题，支持多选、自定义回答和逐题切换，全部回答后一起提交。Python SDK 的 `run.answer` 可以提交问卷答案。
- Claude Code 会话会在对话中显示当前阶段，例如准备中、思考、调用工具、生成回复。
- Claude Code 后台启动失败的原因会显示在状态栏中；连接断开后会自动重连并恢复对话。
- Claude Code 可以设置自动压缩阈值；Claude 原生任务工具的结果显示为待办列表。
- 上下文统计按每次请求检查提示缓存是否被复用，并显示检测覆盖情况。
- 费用只显示提供方报告的数值，没有报告时显示“未报告”。
- 会话数据库会在后台清理旧的请求抓取记录、压缩数据库文件，并显示进度；磁盘空间不足时会给出提示。
- Claude 订阅模型列表更新为 Opus 5.5（默认）、Fable 5.1、Sonnet 5.5、Haiku 5.5。
- Python SDK 新增 `worktrees.defaults()`，创建 worktree 时可以省略目录；合并任务新增 `all_changes()` 和 `set_text()`。

### v0.9.1（修复）

- 运行中新打开的工作区窗口和工作台窗口，现在也能从电脑拖入文件。
- 知识文档在后台自动保存，保存时不再锁住标题和属性按钮，页面布局也不会跳动。
- 只有 CSV 知识文档会显示未保存标记；文件编辑器自动保存时不再闪现磁盘冲突提示。
- 重命名 Markdown 文档标题时，输入框保持焦点。
- Markdown 表格的长单元格在可用宽度内换行；横向滚动时首列固定，并显示边缘阴影。
- `@` 提及和全局搜索中，文件名匹配排在路径匹配前面，分散在长路径中的零散匹配不再出现。
- 排队消息和中途插入的消息在确认送达前不会丢失，也不会重复发送。未送达的消息会保留并标记为“未送达”，可以编辑或重新发送。
- Codex 服务拒绝插入消息时，本会话会停用插入并重试请求。
- 使用 Anthropic 格式端点进行网页搜索时，之前的搜索结果按原始格式回传给模型，模型不再把搜索结果当作自己写的内容并编造结果。
- `web_fetch` 能识别没有声明编码的网页，每次重定向都会检查目标地址，转换大型 HTML 页面更稳定。
- Grep 和 Claude Code 的 Grep 改用同一个搜索引擎，大型工作区中搜索更快。
- Locus 的 Unity 插件可以在更早的 Unity 版本中编译。不支持的功能（帧时间统计、空间截图）会说明所需的 Unity 版本。
- Unity 测试开始时报告的是筛选后实际运行的测试数量。
- Unity 资产中的列表保留原有格式，只写入改动的元素。
- 会话导出和分叉不再复制整个数据库，大型数据库也能顺利完成。
- 模型请求的完整抓取只在调试模式下记录，避免会话数据库快速增长。
- 数据目录被另一个 Locus 进程占用时，启动会弹窗说明原因，而不是直接崩溃。
- Git 分支列表能正确处理已在其他 worktree 中检出的分支和分离的 HEAD。
- 工作区树中的“删除工作区”改为“移除工作区”，这个操作只从树中移除，不删除文件。

### v0.9.1（移除）

- 设置中的资源页不再限制同时运行的会话、Unity Editor、工作区服务、代码语言服务和编译任务的数量，只保留空闲超时。旧配置中的这些数量设置会被忽略。
- Claude Code 和 Codex 会话不再提供 Locus 的 `web_fetch` 工具，改用各自内置的网页工具。其他模型仍然可以使用 `web_fetch`。

### v0.9.0（新增）

- 在工作区选择器上右键工作区，可以在独立窗口内打开该工作区。
- View 可以设置自己的名称和图标（内置图标或自己的 SVG），并可选择每个 View 在标签页还是新窗口中打开。
- 右键 View 即可修改设置、导出、在 Unity 中打开等。插件自带的 View 会标明来源，避免被误删。
- 聊天输入框可以 `@` 提及 View，全局搜索也能找到 View。
- View 可以读取和修改 Markdown 文档的属性和正文，方便基于文档制作表格、看板等工具。
