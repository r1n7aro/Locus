Locus 的协作能力关注的是：当 Agent 在 Unity 项目里做出修改之后，人类如何看清这些修改、决定是否接受，以及在需要时把工作交接给其他开发者。

它不是一个实时多人协作系统，也不提供云端团队空间或在线权限管理。它的目标是把 AI 修改纳入开发者已经熟悉的版本控制与审阅流程。

## 主要能力

- **可视化 Git**：在统一的工作台中查看历史图谱、分支、staged / unstaged / 冲突区，处理提交、stash 与 submodule。
- **Unity 资产语义 diff**：对 Scene、Prefab、ScriptableObject 等 YAML 资产进行结构化展示，而不是逐行字节对比。
- **Workspace 状态**：把当前会话、修改与项目状态保留在工作区中，便于稍后回到上下文。
- **Agent 操作可追踪**：Agent 的修改会落到文件系统与 Git 记录里，可以像审阅人类提交一样审阅它们。

## 典型使用场景

- 审查 Agent 这一轮改了哪些代码与资产
- 通过语义化的 diff 理解资产层面的变化
- 中断后回到工作区，恢复之前的会话与改动上下文
- 把 AI 完成的一段修改交给人类开发者继续接手

## 当前阶段

Locus 仍处于 v0.2.3 早期测试阶段，协作相关能力仍在持续建设。建议在合并 AI 修改之前，结合 Git 历史与语义 diff 进行人工确认。
